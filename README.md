# CAR-SERVICE · АвтоСервис

Нативное Android-приложение для сервисного центра: каталог автомобилей, поиск по марке, модели, году, кузову и коду двигателя, сервисные разделы, регламентные процедуры и список работ с ориентировочными ценами.

## Что уже работает

- офлайн-стартовый каталог популярных конфигураций 2000+;
- экран автомобиля с разделами: ТО, двигатель, трансмиссия, ходовая, электрика и кузов;
- открытие процедуры внутри приложения с пошаговой инструкцией и предупреждениями по безопасности;
- автоматический перевод описаний на русский через Google ML Kit Translation. Модель скачивается по необходимости; для недоступного языка используется подготовленный русский текст;
- онлайн-поиск по конкретной работе и конфигурации автомобиля прямо в приложении: общая выдача, форумы, руководства и видео;
- отдельный каталог работ сервиса с поиском, фильтрами, сроком и ориентировочной стоимостью;
- проверка новой версии через GitHub Releases и кнопка обновления в приложении;
- GitHub Actions для debug-проверки на каждый push и публикации подписанного APK по тегу `v*`.

## Запуск

Откройте проект в Android Studio Ladybug или новее и запустите `app`.

```bash
./gradlew assembleDebug
```

В репозитории нет скачанных мануалов производителей: полный OEM-архив защищён авторским правом, часто продаётся по подписке и отличается по VIN, рынку, кузову и коду двигателя. Поэтому приложение не копирует чужие PDF, а ищет актуальные открытые материалы по конкретной задаче в интернете. Кнопка `Найти уточнения в интернете` доступна в каждом разделе руководства и у каждой работы сервиса; выдача открывается внутри приложения и разделена на общий поиск, форумы, мануалы и видео.

Локальный каталог отделён от UI в `Models.kt`, поэтому его можно расширять легальным API, собственными материалами сервиса или синхронизацией. Онлайн-выдача — вспомогательный источник, а не замена заводской документации: моменты затяжки, допуски, безопасность и отзывные кампании нужно сверять с OEM-источником.

## Подпись и релизы

Ключ не хранится в Git. Для постоянной подписи один раз создайте release-keystore, сохраните его в GitHub Secrets и не меняйте после первой публикации:

- `CAR_SERVICE_KEYSTORE_BASE64` — keystore в base64;
- `CAR_SERVICE_KEYSTORE_PASSWORD`;
- `CAR_SERVICE_KEY_ALIAS`;
- `CAR_SERVICE_KEY_PASSWORD`.

После этого `git tag v1.0.1 && git push origin v1.0.1` запускает GitHub Actions, собирает и публикует подписанный APK. Раннеры не генерируют новый ключ: используется один и тот же secret. Проверки запускаются на push и pull request, а `workflow_dispatch` позволяет запустить релиз вручную.

Приложение проверяет `https://api.github.com/repos/zigorminsk-debug/CAR-SERVICE/releases/latest`; если версия новее установленной, показывает баннер и открывает страницу GitHub Release для установки APK. Android всё равно требует подтверждение установки из внешнего источника — это ограничение ОС, а не бесшумное обновление.
